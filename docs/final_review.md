## 1. 계획대로 된 것

### 1.1 구조와 파일
- 소스 7개 파일이 계획서 6절 표의 `src_files` 와 정확히 같다: `pyproject.toml`, `__init__.py`, `models.py`, `driving_range.py`, `status.py`, `pricing.py`, `route_list.py`, `recommend.py`, `planner.py`. 소스 쪽 계획 밖 파일 없음(forgetting-curve 의 `src/tomllib.py` 같은 우회 파일 없음).
- 의존 그래프 p1 → {p2, p3, p4} → p5 → p6 → p7 대로 import 가 흐른다. 역방향 import 없음.
- 공개 API(계획서 3.5절)의 이름이 모두 있다. `from ev_charge_planner import plan, PlanResult, Route, Vehicle, User …` 가 되고 `__all__` 에 15개가 들어 있다.
- 실행 환경(0절): Python 3.10.0, `requires-python = ">=3.10"`, 3.11 전용 모듈(`tomllib`, `StrEnum`, `datetime.UTC`, `typing.Self`) 미사용, Enum 은 `class X(str, Enum)`. pytest 설정 `pythonpath = ["src"]`, `testpaths = ["tests"]`. 공용 conftest 없음.

### 1.2 공통 규칙(3절)
- 모든 계산 float, 반올림 없음(grep 으로 확인). 라운드 2 에서 비정수 가격 테스트가 p4(283.305)·p5(319.5, 299.997)·p6(287.55)·p7(299.997)에 들어가 잠겼다.
- 경계 허용 오차 1e-9: `driving_range.can_reach`, `recommend` 예비 도달 검사 둘 다 적용.
- naive/aware 섞임 → ValueError(`status.py`). 데이터클래스 검증은 `__post_init__` 에서 ValueError. "결과 없음"은 예외가 아니라 `status="no_safe_station"` + 경고.
- Alert 코드 7개가 3.4 표의 값과 같다. 테스트는 code 만 검사(message 는 한글 자유 문장).
- 소스가 현재 시각을 부르지 않는다(p1 테스트가 AST 로 `src/` 전체 검사 + 이 세션 grep).
