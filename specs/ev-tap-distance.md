# 요구사항: 지도에서 누른 지점까지 현 위치에서 거리 표시

출처: 2026-11-23 묘성 음성. 새 지휘 스크립트(뼈대)의 '진짜 시험' 과제. `00_위키/프로젝트/전기차 충전 계획 앱.md` '보관' 절의 "지점을 누르면 현 위치에서 거리 표시" 하나만 한다.
목적: 운전 중 지도에서 한 곳을 누르면, 지금 내 위치에서 그곳까지 직선 거리를 바로 보여 준다.
시험 조건(묘성): 부분 2~3개, 부분끼리 데이터를 주고받는다, 기존 1차 내비게이터 소스에 기능을 더한다. 걸린 시간을 기록한다(시작·끝 시각은 실행 기록에서 읽는다).

## 대상 저장소와 기댈 자리
- 저장소: `10_프로젝트/ev-charge-planner/` (폰 웹 앱 '충전 길잡이'. 지도 탭·내 위치·길찾기 내비가 모두 여기 `web/` 에 있다. `ev-route-navi` 는 길찾기 파이썬 엔진이고 그 JS 판이 이 저장소의 `web/navi.js`, `ev-charge-map` 은 지도 화면이 없는 파이썬 패키지라 대상이 아니다.)
- 기댈 자리(고칠 곳 후보 — 정확한 줄은 계획 세션이 정한다):
  - `web/app.js` 지도 만들기 `openMap()` — `window.L.map("map", …)` 을 처음 만드는 곳. 여기에 `map.on("click", …)` 을 더한다(지금은 지도 빈 곳 누르기 처리가 없다).
  - `web/app.js` 내 위치 받기 `startWatch()` → `onMapFix(p)` — `navigator.geolocation.watchPosition` 결과로 `mapMe`(내 위치 점)·`mapAcc`(정확도 원)를 놓는다. 마지막 위치·정확도·받은 시각을 여기서 얻는다. 권한 거절(`e.code === 1`)·위치 못 받음·안전하지 않은 주소(`isSecureContext === false`) 안내도 여기 있다.
  - `web/app.js` 충전소 풍선 `drawMap()`(길 위 충전소, `popupHtml(e, x)`)와 주변 충전소(`arPopup(st, s)`) — `L.marker(...).bindPopup(...)`. 풍선 글은 `web/relay.js` 의 `RL.popupHtml(lines)` 가 이스케이프한다.
  - `web/index.html` 지도 칸 `#view-map`(그 안 `#map`, `#map-msg`, `#map-note`, `#map-follow`), `web/style.css`(밝은·어두운 색 변수, `prefers-color-scheme: dark` 와 `data-theme`).
  - `web/build.js` — `web/` 의 스크립트를 한 파일(`web/dist/index.html`)로 합친다. 새 스크립트·설정 파일은 여기 목록에 넣어야 폰 화면에 들어간다.
  - 가짜 화면 `tests/test_integration_dom.js` 의 `boot()`(가짜 Leaflet: `app.leaf.map._h["click"]` 로 지도 누르기 처리기를 꺼낼 수 있다). 잠긴 파일이라 고치지 않고 불러 쓴다.
- 고치지 않는 것: `web/engine.js`, `web/navi.js`, `web/around.js`, `web/relay.js`, `web/live_build.js`, 앞의 잠긴 테스트(`tests.lock.json`), `src/`(파이썬 엔진).

## 사용자가 보는 동작
1. 지도 탭에서 **지도 빈 곳**을 누르면:
   - 누른 자리에 작은 표시(점)가 하나 생긴다(앞에 누른 표시는 지운다 — 늘 하나).
   - 화면 오른쪽에 거리 표시 `#map-tap` 이 나온다 — 상용 내비가 다음 휴게소까지 거리를 보여 주듯 큼지막한 숫자(묘성 11/23 음성: 아래 띠도 풍선도 아님). 큰 거리 숫자 + 그 아래 작은 글 "내 위치에서 직선 거리". 예: **`2.4 km`** 내 위치에서 직선 거리.
   - 거리 표시 오른쪽에 닫기 단추(접근성 이름 "거리 닫기", 터치 영역 48dp 이상). 닫으면 거리 표시와 점이 사라진다.
2. **충전소 풍선**(길 위·주변 충전소)을 눌러 열면, 풍선 맨 아래 줄에 같은 꼴로 "내 위치에서 직선 2.4 km" 를 더한다. 이때 지도 빈 곳 거리 표시는 나오지 않는다(지도 누르기와 겹치지 않게 — 마커 누르기는 지도 click 으로 번지지 않는지 계획에서 확인).
3. 거리 표시가 떠 있는 동안 내 위치가 새로 들어오면(`onMapFix`) 거리를 다시 계산해 거리 표시 숫자를 바꾼다. 누른 지점은 그대로.
4. 거리 글자 꼴(값은 설정):
   - `near_m` 미만이면 숫자 대신 "바로 근처예요".
   - `near_m` 이상 `meter_max_m` 미만이면 미터, `meter_step_m` 단위로 반올림: `350 m`.
   - `meter_max_m` 이상 `km_one_decimal_max_km` 미만이면 km 소수 한 자리: `2.4 km`.
   - 그 이상이면 km 정수: `37 km`.
   - 반올림은 '반올림(half up)'. 경계값(정확히 `near_m`, `meter_max_m`, `km_one_decimal_max_km`)은 위쪽 구간에 넣는다. 반올림한 미터가 `meter_max_m` 에 닿으면 km 꼴로 쓴다(예: 995 m → `1.0 km`, "1000 m" 은 나오지 않는다).
   - 숫자와 단위 사이 한 칸. 천 단위 쉼표는 쓰지 않는다.

## 거리 계산
- 직선 거리(대권 거리, 하버사인). 지구 반지름은 설정 `earth_radius_km`(기본 6371.0088 — `web/navi.js` 와 같은 값). `navi.js` 의 `haversine` 은 밖으로 내보내지 않으므로 새 모듈에 따로 둔다(`navi.js` 를 고치지 않는다).
- 입력 검사: 위도 −90~90, 경도 −180~180, 숫자(NaN·Infinity 아님)가 아니면 계산하지 않고 상태 `bad_input` 을 돌려준다(화면에는 거리 표시를 띄우지 않는다).
- 정확도: 내 위치 정확도(`coords.accuracy`, m)가 계산한 거리보다 크면 상태 `near` 와 같게 "바로 근처예요"로 쓴다(정확도보다 짧은 거리는 믿을 수 없다).
- 오래된 위치: 마지막 위치가 `stale_s` 초보다 오래됐으면 거리는 보이되 거리 표시 아래 작은 글로 "N분 전 위치 기준"(N 은 내림 정수, 1분 미만이면 "방금 전 위치 기준")을 붙인다.

## 경계 (현재 위치가 없을 때 등)
| 경우 | 거리 표시에 보이는 것 | 상태 |
|---|---|---|
| 위치를 아직 못 받음(앱을 막 열었음) | "내 위치를 찾는 중이에요. 잠시 뒤 다시 눌러 주세요." 거리 숫자 없음 | `no_fix` |
| 위치 권한 거절(`code 1`) | "위치 권한이 꺼져 있어 거리를 잴 수 없어요." | `denied` |
| 안전하지 않은 주소·위치 기능 없음 | "이 화면에서는 내 위치를 알 수 없어 거리를 잴 수 없어요." | `unsupported` |
| 위치를 받다가 실패(시간 초과 등) | "지금 위치를 받지 못하고 있어요." | `no_fix` |
| `near_m` 미만 또는 정확도보다 가까움 | "바로 근처예요" | `near` |
| 입력이 이상함 | 거리 표시 없음 | `bad_input` |
- 이 경우들에도 누른 자리의 점은 찍고, 위치가 들어오면(3번 동작) 그때 거리로 바뀐다.
- 화면 글은 `textContent` 로만 넣는다(사용자 입력·API 글을 HTML 로 넣지 않는다). 풍선에 더하는 줄은 `RL.popupHtml` 의 줄 형식으로 넘겨 이스케이프를 그대로 탄다.

## 설정 값 (`web/config_tap.json`, 코드에 박지 않는다)
| 키 | 뜻 | 기본 제안 |
|---|---|---|
| `earth_radius_km` | 하버사인 지구 반지름 | 6371.0088 |
| `near_m` | 이보다 가까우면 "바로 근처예요" | 30 |
| `meter_max_m` | 이 미만이면 m 로 | 1000 |
| `meter_step_m` | m 반올림 단위 | 10 |
| `km_one_decimal_max_km` | 이 미만이면 km 소수 한 자리 | 10 |
| `stale_s` | 이보다 오래된 위치면 "N분 전" 표시 | 60 |
| `texts` | 위 표의 안내 글들(키: `near`, `no_fix`, `denied`, `unsupported`, `fail`, `suffix`, `popup_prefix`, `stale_min`, `stale_now`, `close_label`) | 위 표의 글 |
- `web/build.js` 가 이 파일을 한 파일 빌드에 넣는다(예: `window.EV_TAP_CONFIG = {…}`). 파일이 없거나 키가 빠지면 거리 표시 대신 `#map-msg` 에 "거리 설정을 읽지 못했어요" 를 보이고, 기본값을 코드에 두고 쓰지 않는다.

## 부분 나누기 제안 (계획 세션이 최종으로 정한다)
| 부분 | 하는 일 | 파일 | 기대는 부분 |
|---|---|---|---|
| `t1_calc` | 설정 읽기 검사 + 거리 계산 + 글자 꼴 만들기. 화면 없음, 순수 함수 | `web/tapdist.js`(새, `around.js` 처럼 node `module.exports` 와 브라우저 `window.EvTapDist` 둘 다), `web/config_tap.json`(새) | - |
| `t2_screen` | 지도 누르기·풍선 줄·거리 표시·닫기·위치 갱신 때 다시 계산·경계 안내. 상태별 글을 거리 표시에 놓기 | `web/app.js`, `web/index.html`, `web/style.css` | `t1_calc` |
| `t3_build` (통합) | `build.js` 가 `tapdist.js`·`config_tap.json` 을 넣고, 가짜 화면 `boot()` 로 처음부터 끝까지: 위치 받기 → 지도 누르기 → 거리 표시 숫자 → 위치 바뀜 → 숫자 바뀜 → 닫기 | `web/build.js` | `t1_calc`, `t2_screen` |

부분끼리 넘기는 것(약속 문서 2-6 `gives`):
- g1 `t1_calc` → `t2_screen` (tcp): `EvTapDist.measure(me, tap, cfg, nowMs)` 가 돌려주는 값. 모양 `{"state":"ok|near|no_fix|denied|unsupported|bad_input","meters":수|null,"text":"글","stale_note":"글|null"}`. `me` 는 `{"lat":수,"lng":수,"accuracy":수,"at":밀리초}` 또는 `null`(`null` 이면 `no_fix`), `tap` 은 `{"lat":수,"lng":수}`. 권한 거절·지원 안 됨은 `me` 대신 `{"error":"denied|unsupported|fail"}` 로 넘긴다.
- g2 `t1_calc` → `t2_screen` (tcp): 설정 읽기 `EvTapDist.loadConfig(obj)` 의 결과 `{"ok":참거짓,"cfg":{…}|null,"missing":["키",…]}`.
- g3 `t2_screen` → `t3_build` (tcp): 화면이 남기는 상태 — `#map-tap` 의 `hidden`, 거리 글(`textContent`), `dataset.state`(위 state 와 같은 낱말), 누른 점의 위치. 통합 테스트는 이 셋만 보고 판단한다.

## 끝 기준 (테스트로 확인)
t1_calc
- 같은 점 → `meters` 0, `state` `near`.
- 서울역(37.5547, 126.9707) → 부산역(35.1151, 129.0414) 을 하버사인 공식으로 직접 계산한 값과 `meters` 차이 1m 미만, 글 꼴은 km 정수.
- 설정 값으로 경계 사례 표: `near_m`−1·`near_m`·`meter_max_m`−6(반올림해 `meter_max_m` 에 닿음 → km)·`meter_max_m`·`km_one_decimal_max_km` 직전·직후 — 각 글자 꼴이 위 규칙대로.
- 정확도가 거리보다 크면 `near`. 위도 91, 경도 NaN → `bad_input`. `me` 가 `null` → `no_fix`, `{"error":"denied"}` → `denied`.
- `at` 이 `stale_s` 초 넘게 지나면 `stale_note` 가 "N분 전 위치 기준"(내림), 안 지나면 `null`.
- 설정에서 키 하나를 빼면 `loadConfig` 가 `ok:false` 와 그 키를 `missing` 에 준다. 새 코드(`tapdist.js`)에 설정 키 값과 같은 숫자 글자가 박혀 있지 않다(테스트가 소스에서 설정 값 숫자를 찾아 없음을 확인 — 0·1 같은 계산용 수는 뺀다, 계획에서 목록을 정한다).
t2_screen
- 위치를 받은 뒤 지도 빈 곳 누르기 → `#map-tap` 이 보이고 `dataset.state` `ok`, 글에 t1 이 만든 거리 글이 그대로 든다.
- 위치 전 누르기 → `no_fix` 글, 권한 거절 뒤 누르기 → `denied` 글. 점은 찍힌다.
- 거리 표시가 떠 있는 채로 새 위치가 들어오면 숫자가 새 거리로 바뀐다(누른 점은 그대로).
- 닫기 → 거리 표시 `hidden`, 점 지워짐. 다시 누르면 점은 하나뿐.
- 충전소 풍선 글 맨 아래에 거리 줄이 있고, 풍선 글은 이스케이프된다(충전소 이름에 `<b>` 가 들어도 태그로 안 들어감).
- 닫기 단추의 접근성 이름이 설정 `texts.close_label` 과 같다.
t3_build
- `node web/build.js` 뒤 `web/dist/index.html` 에 `tapdist.js` 의 함수 이름과 `config_tap.json` 의 값이 들어 있다.
- 가짜 화면 처음부터 끝까지(위 흐름) 통과. 앞의 잠긴 테스트가 모두 통과한다.

## 넣지 않는 것
- 지도 손으로 돌리기, 주소 자세히 검색, 풍선 대신 남아 있는 정보 패널(이번 거리 표시는 거리 숫자뿐), 다른 내비 앱으로 연결, 공공 데이터 장소, 오른쪽 가까운 충전소 두 곳.
- 도로 거리·걸리는 시간(외부 길찾기 API 를 부르지 않는다 — 직선 거리만, 네트워크 없음).
- 거리 기록 저장, 설정 화면에서 값 바꾸기.

## 앱 디자인 규칙 가운데 닿는 것 (프로젝트 지침)
- 거리 표시는 화면 오른쪽 가장자리에 붙은 평평한 칸(상용 내비의 다음 휴게소 거리 칸처럼, 지도 누르기를 가리지 않는 크기)이고 카드처럼 띄우지 않는다(그림자 과하게 없음, 그라데이션·유리 효과 없음). 간격 8dp 단위.
- 색은 `style.css` 의 기존 변수만(`--surface`, `--ink`, `--ink-2`, `--line` 등). 새 색을 만들지 않는다. 어두운 모드(`prefers-color-scheme: dark`, `data-theme="dark"`)에서도 글자 대비 기준을 지킨다.
- 거리 숫자는 크게(거리 표시 안 가장 큰 글, 운전 중 한눈에 읽히게), 나머지는 작은 글. 시스템 글자 크기를 따른다(px 고정 대신 rem).
- 닫기 단추·누른 점 근처 조작은 최소 48dp. 아이콘은 Material Symbols 또는 글자("닫기") — 이모지 금지.
- 문구는 짧은 존댓말, 느낌표 없음.
- 상태 화면: 위 경계 표가 거리 표시의 로딩(`no_fix` — 찾는 중)·오류(`denied`·`unsupported`·`fail`) 상태다. 오프라인이어도 거리 계산은 된다(네트워크 안 씀).
- 검수: 8 전체 검증에서 밝은·어두운 화면 스크린샷을 한 장씩 남긴다(헤드리스 Edge 가능하면 — 교훈 34줄).

## 지킬 교훈 (00_위키/교훈.md 에서)
- 하드코딩 금지(139줄): 값은 설정에, 코드는 읽기만.
